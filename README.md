# Isha Intranet

Internal community website for Isha volunteers and staff.

## Getting started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

Copy `.env.example` to `.env.local` and add Google (and optionally Apple) OAuth credentials. Only `@sadhguru.org` and `@sadhguru-ext.org` emails can sign in.
